# DocDesk — Privacy Policy

The public privacy policy for the DocDesk Android app (`com.rslabs.docdesk`) and web app, served as a
static page via GitHub Pages.

**Live URLs**
- Privacy policy: https://riyazshaikh16in.github.io/docdesk-privacy/
- Account deletion: https://riyazshaikh16in.github.io/docdesk-privacy/delete-account/

These are the URLs the Google Play listing, the Data safety form and the "Delete account URL" field
point at. The source of truth lives in the app repo at `store/privacy-site/`; this repo is its
published copy.

## Editing
`index.html` and `delete-account/index.html` are the whole site — no build step. Edit, push to
`main`; GitHub Pages redeploys within a minute. When what is collected changes, update the "Last
updated" date and keep the Play Data safety form in sync.
